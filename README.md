# Sost — Ethiopian Time, Calendar & Numeral Converter

A Next.js (App Router, TypeScript, Tailwind CSS v4) port of the Ethiopian
conversion toolkit: world time → East Africa Time, Gregorian ↔ Ethiopian
calendar dates, Arabic ↔ Ge'ez numerals, an Orthodox holiday & fasting
calendar, and an age calculator.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

For a production build:

```bash
npm run build
npm run start
```
